# Nature Experience Amami 顧客・予約管理アプリ（試作）

## 今回の試作でできること

- 問い合わせ文章をそのまま貼り付け
- 「AI整理（試作）」で氏名・電話・メール・日付・人数・ホテル・観察希望を簡易抽出
- 不足している基本情報を表示
- 希望日の状態（空き／他のお客様のガイド／自分の予定／休業）を選択
- 近い候補日を2つ設定
- 返信文を自動作成
- 返信文をコピー
- 問い合わせを「未確定」で保存
- 一覧から検索
- 「予約確定」に変更
- 詳細画面で、人数分の参加者情報（氏名・年齢・靴のサイズ）を記入・保存
- データは現在このブラウザのlocalStorageに保存

## 起動方法

このフォルダをVS Codeなどで開き、ローカルサーバーで `index.html` を表示してください。

例：
- VS CodeのLive Server
- `python -m http.server 8000`

## 重要

現在の「AI整理」は、実際のGeminiやiPhoneローカルAIにはまだ接続していません。
まず画面・操作・データ項目を固めるための試作です。

次の段階で、
1. 本物のAI APIに接続
2. 予約カレンダーを追加
3. 1週間前・3日前通知を追加
4. 必要ならローカルAIを利用する構成を検討

という順番で拡張できます。

## 個人情報について

この試作はlocalStorageを使うだけなので、本番の顧客管理としてそのまま使う設計ではありません。
本番版ではログイン、データベース、バックアップ、アクセス制御、AIへ送る情報の範囲などを別途設計します。
