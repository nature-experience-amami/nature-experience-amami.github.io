# Nature Experience Amami 顧客・予約管理アプリ（試作）

## 今回の試作でできること

- 問い合わせ文章をそのまま貼り付け
- 「AI整理」で氏名・電話・メール・日付・人数・ホテル・観察希望・参加者情報(氏名/年齢/靴サイズ)をAI(Gemini)が読み取って自動入力(サイト本体と同じCloudflare Workerを利用。通信に失敗した時は簡易抽出にフォールバック)
- 返信文もAIが、過去の返信の見本(文体)と料金などの業務情報をもとに下書きを作成
- 不足している基本情報を表示
- 希望日の状態（空き／他のお客様のガイド／自分の予定／休業）を選択
- 近い候補日を2つ設定
- 返信文を自動作成
- 返信文をコピー
- 問い合わせを「未確定」で保存
- 一覧から検索
- 「予約確定」に変更
- 詳細画面で、人数分の参加者情報（氏名・年齢・靴のサイズ）を記入・保存
- パスワードで暗号化したバックアップファイルの書き出し・復元
- 「🔄 更新を確認」ボタンで、ホーム画面のアプリを消さずに最新版へ更新
- データは現在このブラウザのlocalStorageに保存

## 更新時の注意

`app.js`・`style.css` を直したら、`index.html` の `?v=` の数字を1つ上げてください。
そうしないと、すでにホーム画面に追加している人の端末で「🔄 更新を確認」を押しても、
古いファイルのままキャッシュされ続けることがあります。

## 起動方法

このフォルダをVS Codeなどで開き、ローカルサーバーで `index.html` を表示してください。

例：
- VS CodeのLive Server
- `python -m http.server 8000`

## AIについて

「AI整理」「返信文の作成」は、サイト本体のAI質問機能と同じCloudflare Worker(`Worker · JS`)経由でGeminiを呼び出している。
返信文の見本・料金などの固定情報は `app.js` の `REPLY_EXAMPLES` / `GUIDE_FACTS` にある。
見本の返信例を差し替えたい・料金が変わった、などの時はここを直す。

お客様の氏名・電話番号・メールアドレスなどが処理のためGemini APIに送信される。無料枠のAPIだと
送信内容がGoogleのモデル改善に使われる可能性があるため、気になる場合は有料プランへの切り替えを検討する。

次の段階で、
1. 予約カレンダーを追加
2. 1週間前・3日前通知を追加

という順番で拡張できる。

## 個人情報について

この試作はlocalStorageを使うだけなので、本番の顧客管理としてそのまま使う設計ではありません。
本番版ではログイン、データベース、アクセス制御などを別途設計します。
